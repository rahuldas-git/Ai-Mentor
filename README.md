# 🤖 AI Life & Career Mentor (CLI)

A command-line interface (CLI) AI assistant built with Node.js and Google's Gemini API (`@google/genai`). This AI acts as an empathetic, wise, and highly practical mentor to guide users through life's challenges, academic pressures, and career growth.

## ✨ Features
- **Context-Aware Mentoring:** Pre-configured with system instructions to act as a supportive and practical life/career mentor.
- **Persistent Chat History:** Automatically saves your conversation in a local `chat-history.json` file so the AI remembers previous context in the same session.
- **Interactive CLI:** Real-time terminal-based chat using Node.js `readline`.

## 🛠️ Tech Stack
- **Node.js** (ES Modules)
- **@google/genai** (Google Gemini SDK)
- **dotenv** (Environment variable management)
